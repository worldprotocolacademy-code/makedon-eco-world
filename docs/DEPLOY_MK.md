# Безбедна инсталација — v11.0 RC1

1. Провери го SHA-256 манифестот и отвори ја HTML-датотеката локално. Тестирај празен старт, внес, документирање, JSON/CSV backup и HR/MK/EN.
2. Зачувај го постојниот v10 `main` commit и тековната поставка на Pages. Не бриши root `index.html`, постојни JS модули или лиценца. Git clone од работната средина не беше можен (DNS); не е креирана remote гранка или commit.
3. По одобрување, во GitHub креирај гранка `feat/mew-v11-green-bridge` од актуелниот `main`. Додај само `pilot-v11/index.html` и, по потреба, документацијата во `docs/`. Не прикачувај тест-податоци, приватна кореспонденција или клучеви. Креирај PR; не merge автоматски.
4. За приватен прием користи локален web server или одобрена тест-околина. Не користи јавен GitHub PR како приватна средина: јавен репозиториум може да го направи кодот видлив пред merge. За реален пилот подобро е изолиран HTTPS origin (посебен subdomain) за да не го дели localStorage со други WPA страници. Локалниот дневник не е шифриран и нема синхронизација.
5. Ако GitHub Pages навистина го опслужува наведениот WPA path, по одобрен merge очекуваната патека е `https://worldprotocolacademy.mk/makedon-eco-world/pilot-v11/`. Ова е предложена адреса, НЕ потврдена live адреса. Прво провери како е поставено рутирањето на доменот. Провери HTTPS, HTTP статус, визуелен приказ, localStorage по reload, реален export/import, сите локализации и изворни линкови. Повтори го приемниот пример на Android и iOS.
6. Човечка порта 1: одобрување на поставувањето. Човечка порта 2: одобрување на јавниот линк по приемниот тест. Човечка порта 3: одобрување на испраќањето до Марио. Не ветувај партнерство или исплати.
7. Стариот v10 има неподдржани јавни тврдења. Пред поширока јавна презентација, одделно одобри замена на root со проверениот пилот или архивирање на v10 со јасна демонстрациска ознака. Не ја нарекувај старата страница продукциски сервис.

## Rollback
Адитивната патека не бара промена на root. Ако новиот пилот е поставен, отстрани ја само новата патека преку revert на одобрениот commit и повторно провери ја старата рута. Ако root е заменет со посебен одобрен commit, врати го претходниот потврден commit. Локалните податоци не се серверски: backup JSON е единствената пренослива резервна копија од RC1.
